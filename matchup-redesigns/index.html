RED vs BLUE · Matchups Redesign
Design exploration · 10 directions

Setting up Red vs Blue games,
without the dropdown grind.

Ten ways to make court matchups faster to set up for admins and clearer to read for everyone watching. Each concept pairs an admin setup method (light) with the matching live viewer display (dark), using the real squad and the app's own colours. Ordered safe → bold. A few are interactive — try them.

Today · Admin

Per court: 4 dropdowns (scroll a long list ×4) + two stepper scores + court no. + status. ≈12+ taps a court, easy to mis-tap.

Today · Viewer

Courts read "TBD / TBD" until every slot is set. Small names, no faces — hard to tell who's on at a glance.

Goal

Fill a court in a couple of taps, and let players across the hall instantly see who's playing whom, and the score.
