Five original directions,
past the Apple look.

The current app leans on system fonts and Apple-blue minimalism — clean, but it could be any tech product. Here are five distinct visual languages for the same member home (welcome, leaderboard, tiers, prize draw), each built from the real brand: the feather mark and warm gold. Tap any screen to open it full-size.

Concept mockups · same real data across all five for a fair comparison

Quietly expensive. Didone serif, oxblood & antique gold, an embossed membership card and an engraved honours board. Reads like a private racquet club.

Bold & confident. Futura-style geometry, primary red/cobalt/yellow, thick rules and shuttle-circle / court-triangle shapes. Playful but serious.
FArcadeRetro Game Scoreboard
Open full ↗
Pure gamification. Tiers become ranks, points become XP, the draw becomes a gacha. CRT scanlines, pixel type, warm neon. The most fun, most polarising.
GRiso ZineRisograph Sports Poster
Open full ↗
Print-shop energy. Spot-ink overprint, halftone dots, registration marks and huge condensed type. Young, loud, very shareable on social.
HTerroirMalaysian Tropical Heritage
Open full ↗
Rooted & local. Jade, terracotta and gold, the feather used as foliage, fully bilingual EN + 中文. Feels like an Ipoh institution, not a generic app.

Each screen is a standalone HTML file in this folder (D–H). They share identical content — the same eight members, tier thresholds and June prize draw — so you're comparing design, not data. None use SF Pro, Apple blue or the GitHub-style palette of the live app.
